# 开发中

仍在开发中的 skill。尚未准备好发布——预计有粗糙边缘、破坏性变更和废弃的实验。它们在毕业到稳定分类之前被排除在插件和顶层 README 之外。

- **[review](./review/SKILL.md)** — 沿两个平行轴审查自固定点以来的变更：**标准**（diff 是否遵循仓库的编码标准？）和 **规格**（diff 是否忠实地实现了原始 issue/PRD？）。
- **[writing-beats](./writing-beats/SKILL.md)** — 以节拍之旅的形状构建文章，选择你自己的冒险风格。挑选一个起始节拍，只写那个节拍，然后转向下一个，直到文章自然结束。
- **[writing-fragments](./writing-fragments/SKILL.md)** — 烤问会话，挖掘你的碎片——异质的写作片段（主张、小故事、犀利句子、半成品想法）——并追加到单个文档中，作为未来文章的原材料。
- **[writing-shape](./writing-shape/SKILL.md)** — 拿一份 markdown 格式的原材料，逐段将其塑造成文章，在每一步讨论格式选择。
