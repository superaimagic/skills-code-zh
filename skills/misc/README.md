# Misc

我留着但不常用的工具。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** — 设置 Claude Code hook 来阻止危险 git 命令（push、reset --hard、clean 等）在执行前被拦截。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — 将测试文件从 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)** — 创建带有章节、问题、解答和解释的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — 设置 Husky pre-commit hook，包含 lint-staged、Prettier、类型检查和测试。
