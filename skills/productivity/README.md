# Productivity

通用工作流工具，非代码特定。

- **[caveman](./caveman/SKILL.md)** — 超压缩通信模式。削减约 75% token 用量，去掉填充词同时保持完整技术准确性。
- **[grill-me](./grill-me/SKILL.md)** — 对计划或设计进行无情面试，直到决策树的每个分支都被解决。
- **[handoff](./handoff/SKILL.md)** — 将当前对话压缩成交接文档，以便另一个 agent 继续工作。
- **[write-a-skill](./write-a-skill/SKILL.md)** — 创建具有正确结构、渐进式信息披露和捆绑资源的新 skill。
